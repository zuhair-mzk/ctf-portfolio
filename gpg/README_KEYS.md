# GPG Keys Removed for Educational Integrity

The following GPG key files have been removed from the public repository to maintain the educational integrity of this cryptography challenge:

## Original Key Files:
- `key.asc` - Student GPG public key
- `key2.asc` - Secondary public key  
- `instructorkey.asc` - Instructor's public key
- `private-key.asc` - Private key for decryption
- `zuhair.khan` - Key identifier file

## For Students:
To complete this challenge, you'll need to:
1. Generate your own GPG key pairs using `gpg --gen-key`
2. Create test messages and sign/encrypt them
3. Practice with the GPG command-line interface
4. Work through the verification and decryption processes

## For Instructors:
Please contact the course instructor to obtain:
- Sample GPG keys for the challenge environment
- Signed and encrypted message files
- Flag files with proper GPG signatures
- Complete challenge setup instructions
